### 接口与职责

| 接口或边界 | 当前实现与核对结果 |
| --- | --- |
| `GET /api/me` | 同源读取站点名、登录状态、公开页权限及 `history_days`；公开页关闭且未登录时转到 Hub 后台。 |
| `GET /api/nodes` | 初次读取及断线轮询；`safeNodes` 隔离异常指标；旧 REST 结果不能覆盖较新的 WS 快照。 |
| `GET /api/nodes/{id}/metrics` | 范围随历史保留期生成，资源和延迟分别请求 `series`；按屏幕像素提供 `points`，由 Hub 限制最终分辨率；秒时间戳转换为毫秒。 |
| `/api/ws`、`/api/ws?gzip` | 同源 ws/wss；按浏览器解压能力选择压缩；文本与 Blob 都支持，顺序解码，关闭后的帧丢弃，成功接收才重置断流计时。 |
| `GET /api/themes/monitor-theme-guangao/config` | 与启动请求并行；从清单补默认值，按类型和枚举过滤旧配置；失败回退。计算器开关属于 Hub 站点配置，访客不能用本地偏好重新开启。 |
| 后台、登录及 agent | 由 Hub 提供；主题没有节点管理、认证写接口、agent JSON-RPC 连接或数据库代码。 |
| 汇率辅助接口 | 计算器打开且使用外币时查询 Frankfurter，仅传货币对，不发送节点信息、金额或日期；不携带凭据，超时可手动输入。它是可选外部服务，不是 Monitor 协议接口。 |
| 图标静态请求 | `index.html` 保留 `/favicon.svg` 和 Apple 图标声明；只在识别到主题自身默认 SVG 时切换皮肤图标，自定义图标和检查失败时保留 Hub 图标。 |

### 框架、数据与交付

- React/Vite/TypeScript 生成纯静态 SPA；`App` 负责路由、配置和分组，`lib/api` 负责实时数据，详情历史独立加载并使用 memo，计算器表单和导出在本地处理。
- 演示数据仅进入 Vite 开发插件；生产 JS 未检出本次核对的演示专用字符串。字体、国旗、图标随主题分发，不依赖外部字体服务。
- 使用 Hub 的 `online`、`expires_in`、`last_seen_ago` 和流量累计；兼容旧字段缺失。离线、刚连接尚未上报、异常 metrics 分开处理，缺失指标不冒充零速。
- 分组以首次出现顺序展示，全部使用 `null`、未分组使用空字符串；汇总和节点过滤同步。公开备注、公告及站点标题均按文本渲染。
- 页签隐藏时关闭节点 WS、停止轮询和重试计时，丢弃旧请求结果；恢复前台立即读取并重连。节点路径支持直接打开、刷新与浏览器返回。
- `theme.json` 的七项配置包含合法默认值、唯一 key 和有效枚举；站点配置由 Hub 保存，本地存储仅保存访客皮肤、动效和边框灯偏好。

## 数据与运行方式

- 生产构建为静态 SPA。演示接口仅在 Vite 开发插件中启用；对正式 `dist` 的扫描没有发现演示节点名、演示插件或测试错误页字符串。
- 网速使用 `net_rx/net_tx` 的 B/s 数值；累计及本月流量使用 Hub 返回的统计值，`month_used` 缺失时按 `traffic_mode` 兼容处理，没有从历史曲线积分估算流量。
- 在线状态读取 `online`；指标缺失不会变成零速。单个异常 metrics 不会阻止其他节点展示。
- 分组顺序由节点排序决定，以 `null` 表示全部分组，避免与任意组名碰撞；汇总随选择的分组更新。
- 到期和离线时长优先采用服务端字段，并区分字段缺失与 `null`。费用格式、账期和旧 Hub 兼容已有单元校验。
- 公告和节点备注采用 React 文本渲染，无原始 HTML 注入。站点设置读取 Hub；本地存储仅保存访客配色、动效和边框灯偏好。
- 页面隐藏时停止节点连接、轮询及重试，忽略旧请求结果；恢复前台立即读取并重连。该行为通过模拟可见性事件验证。
- `/node/{id}` 支持刷新、前进和后退，README 已列出反代放行路径；固定路径 favicon 和 Apple 图标声明齐全。
